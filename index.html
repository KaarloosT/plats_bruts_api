Plats Bruts API

API REST estàtica sobre la sitcom catalana Plats Bruts (TV3, 1999-2002). Sense autenticació, sense rate limits.

Inspirada en PokéAPI, exposa les dades de la sèrie com a fitxers JSON estàtics servits per GitHub Pages. Qualsevol pot consumir-la des d'un navegador, una app mòbil o un script — només cal fer fetch.

Projecte de fans, sense afiliació amb TV3 ni la productora. Dades extretes de la Viquipèdia en català sota llicència CC BY-SA 4.0. Tota fitxa inclou un camp font_wikipedia amb la URL d'origen.

URL base

https://kaarloost.github.io/plats_bruts_api/api/v1/

Endpoints

RecursÍndexDetall
Personatges /personatges/index.json /personatges/{slug}.json
Temporades /temporades/index.json /temporades/{n}.json
Episodis /episodis/index.json /episodis/{T}x{NN}.json
Cites /cites/index.json /cites/{id}.json
Localitzacions /localitzacions/index.json /localitzacions/{slug}.json

Cada índex retorna { "count": N, "results": [...] } amb resums per iterar sense baixar totes les fitxes.

Prova-ho ara mateix

/personatges/index.json /personatges/josep-lopes.json /temporades/index.json /episodis/1x01.json /episodis/index.json

Com utilitzar-la

JavaScript (fetch)

const BASE = "https://kaarloost.github.io/plats_bruts_api/api/v1";

// Llegir un personatge
const lopes = await fetch(`${BASE}/personatges/josep-lopes.json`).then(r => r.json());
console.log(lopes.nom); // "Josep Lopes"

// Llistar tots els episodis
const episodis = await fetch(`${BASE}/episodis/index.json`).then(r => r.json());
console.log(`Total episodis: ${episodis.count}`);
episodis.results.forEach(e => console.log(e.id, e.titol));

curl

# Detall d'un episodi
curl https://kaarloost.github.io/plats_bruts_api/api/v1/episodis/1x01.json

# Resum d'una temporada
curl https://kaarloost.github.io/plats_bruts_api/api/v1/temporades/1.json

Python

import requests

BASE = "https://kaarloost.github.io/plats_bruts_api/api/v1"

personatges = requests.get(f"{BASE}/personatges/index.json").json()
for p in personatges["results"]:
    print(p["slug"], "—", p["nom"])

CORS i caché

GitHub Pages serveix les respostes amb Access-Control-Allow-Origin: *, així que pots cridar-la des de qualsevol web. El CDN cacheja els fitxers, així que les peticions són ràpides.

Versionat

Tot viu sota el prefix /api/v1/. Si en el futur cal trencar compatibilitat, es publicarà /api/v2/ i la v1 seguirà funcionant inalterada.

Contribuir

El codi font, els tests i les dades estan a github.com/KaarloosT/plats_bruts_api. Per afegir cites, localitzacions o enriquir personatges, edita data/overrides.json i fes un pull request.
