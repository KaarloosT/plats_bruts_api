Plats Bruts API

API REST estàtica amb dades sobre la sitcom catalana Plats Bruts (TV3, 1999-2002). Sense autenticació, sense límits.

Projecte de fans, sense afiliació amb TV3 ni la productora. Dades extretes de Viquipèdia (CC BY-SA).

URL base

https://<usuari>.github.io/plats-bruts-api/api/v1/

Endpoints

RecursÍndexDetall
Personatges/personatges/index.json/personatges/{slug}.json
Temporades/temporades/index.json/temporades/{n}.json
Episodis/episodis/index.json/episodis/{T}x{NN}.json
Cites/cites/index.json/cites/{id}.json
Localitzacions/localitzacions/index.json/localitzacions/{slug}.json

Exemple amb fetch

const res = await fetch("https://<usuari>.github.io/plats-bruts-api/api/v1/personatges/josep-lopes.json");
const lopes = await res.json();
console.log(lopes.nom);

Exemple amb curl

curl https://<usuari>.github.io/plats-bruts-api/api/v1/episodis/1x01.json
